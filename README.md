# Human Token

Landing page for Unico's Human Token: a WebGL particle experience (a title that breaks into a bust, "How it works", and "How to connect").

Two versions, both static (no build step):

- `index.html`: Version 1
- `version-2.html`: Version 2

The pages are published with GitHub Pages straight from the repository root (`.nojekyll` is there so every file is served as is).
